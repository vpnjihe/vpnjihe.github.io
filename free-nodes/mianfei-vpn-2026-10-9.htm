第三步：搭建科学上网工具——V2Ray与Shadowsocks的实战对决

服务器有了，接下来就是安装代理软件。目前主流的科学上网工具无非是Shadowsocks（简称SS）和V2Ray（尤其是其核心协议VMess）。SS轻量、易配置，适合纯翻墙；V2Ray功能更强，支持伪装成正常HTTPS流量，抗封锁能力更胜一筹。下面我们逐一讲解。

方案A：Shadowsocks——简单粗暴，适合新手

SS的安装流程堪称“一键式”。通过SSH工具（如Xshell、Termius或Windows自带的终端）连接到你的VPS IP，输入root密码登录。然后依次执行以下命令：

bash apt update apt install shadowsocks-libev

安装完成后，编辑配置文件 /etc/shadowsocks-libev/config.json，内容大致如下：

json { "server": "0.0.0.0", "server_port": 8388, "password": "你的强密码", "method": "aes-256-gcm" }

保存退出，重启SS服务：

bash systemctl restart shadowsocks-libev

最后，在你的电脑或手机上安装一个SS客户端（如Windows的Shadowsocks-Windows，macOS的ShadowsocksX-NG，iOS的Shadowrocket，Android的Shadowsocks-Android），填入你的VPS IP、端口、密码和加密方式，开启代理，你就成功突破了封锁。

方案B：V2Ray——功能强大，抗封锁首选

V2Ray的安装稍微复杂，但一条官方推荐的脚本就能搞定。SSH登录后，执行：

bash bash <(curl -L https://raw.githubusercontent.com/v2fly/fhs-install-v2ray/master/install.sh)

脚本会自动安装V2Ray核心。接下来，编辑配置文件 /usr/local/etc/v2ray/config.json，这里我提供一个最基础的VMess配置模板：

json { "inbounds": [{ "port": 10086, "protocol": "vmess", "settings": { "clients": [{ "id": "你的UUID", "alterId": 0 }] } }], "outbounds": [{ "protocol": "freedom" }] }

UUID可以通过执行 cat /proc/sys/kernel/random/uuid 生成。保存后重启V2Ray：

bash systemctl restart v2ray

客户端方面，推荐使用V2RayN（Windows）、V2rayU（macOS）或Kitsunebi（iOS/Android）。填入服务器地址、端口、用户ID和alterId，即可连接。

第四步：优化与维护——让你的科学上网之路更持久

搭建好只是开始，如何让它稳定、高速、不被封才是关键。这里分享几个实用技巧：

1. 开启BBR加速：BBR是Google开发的一种拥塞控制算法，能显著提升网络吞吐量。执行以下命令开启：

bash echo "net.core.default_qdisc=fq" >> /etc/sysctl.conf echo "net.ipv4.tcp_congestion_control=bbr" >> /etc/sysctl.conf sysctl -p

2. 定期更换端口和密钥：如果发现连接速度异常缓慢或频繁断连，很可能是IP被GFW针对性干扰。此时不要犹豫，赶紧更换SS端口（如从8388改为8443）或重新生成V2Ray的UUID。更稳妥的做法是直接销毁VPS，重新部署一台，换一个新IP。

3. 使用CDN伪装：如果你使用V2Ray，可以搭配Cloudflare的CDN服务，将你的域名解析到Cloudflare，然后开启WebSocket+TLS模式。这样你的流量会伪装成正常的HTTPS网页访问，极大降低被识别和封锁的概率。

4. 监控流量：Vultr后台提供实时的流量监控图表，如果发现流量异常暴涨，可能是你的密码泄露或被他人扫描攻击。此时应立即更换密码，并考虑开启防火墙（如UFW）限制只允许你的IP访问。

常见问题FAQ——你踩过的坑，我都替你踩过了

Q1：Vultr服务器IP被墙了怎么办？
A：这是最常遇到的问题。直接登录Vultr后台，选择“Server Destroy”，销毁当前实例，然后重新部署一台。新实例会分配一个全新的IP，大概率是干净的。记住，换IP是常态，不要心疼那几美元。

Q2：为什么我连上了代理但网速极慢？
A：可能原因有三：一是服务器离你太远，延迟高；二是你的带宽跑满，建议升级套餐；三是DNS污染，可以在客户端设置里将远程DNS改为 1.1.1.1 或 8.8.8.8。

Q3：SS和V2Ray哪个更安全？
A：SS的加密协议相对简单，在某些极端情况下可能被深度流量检测识别；V2Ray的VMess协议自带混淆和伪装能力，抗检测性更强。如果你追求极致的稳定性，V2Ray是更好的选择。

Q4：我可以在一台VPS上同时运行SS和V2Ray吗？
A：完全可以。只要端口不同，两者互不干扰。这可以作为备份方案，万一一个被封锁，另一个还能顶上。

Q5：Vultr的计费方式是什么？
A：Vultr按小时计费，精确到秒。你创建服务器后就开始扣费，销毁后立即停止扣费。所以，用完就销毁，不浪费一分钱。

FAQ

Hiddify Next 用户流量配额如何设置？
管理员可为每个用户设置带宽和流量上限，超出限制可自动降速或阻止访问，保证服务器资源合理分配，避免单用户占用过多带宽，提高整体网络公平性和使用效率。
Nekoray 与 Nekobox 有什么不同？
Nekoray 是一款基于 Qt 的跨平台代理前端，而 Nekobox 更偏向移动端简化使用。两者均支持 V2Ray/VLESS/Trojan 协议，但 Nekobox 提供了更轻量的界面和更快的连接启动速度。
V2Ray 如何实现分流规则？
V2Ray 使用 routing 模块实现分流，可根据目标域名、IP、端口或协议类型决定流量走向。用户可自定义多个 outbound，并通过规则实现国内直连、国外代理等智能路由功能。
VLESS + XTLS 如何降低移动网络延迟？
XTLS 通过减少握手次数和加密开销降低延迟。结合策略组和多节点切换，可在高延迟或不稳定的移动网络环境中保持连接稳定，提升网页浏览、视频和游戏体验流畅度。
Trojan 如何实现伪装？
Trojan 使用 TLS 协议模拟正常的 HTTPS 流量，防火墙难以区分其与普通网站访问的区别。通过伪装域名、SNI 和证书匹配机制，它能在保障安全的同时隐藏真实代理流量。
PassWall2 的节点测速结果如何影响分流？
PassWall2 会根据节点延迟和成功率自动调整策略组选择最优节点。测速结果直接影响程序选择出口，从而提高连接速度和稳定性。
VLess 协议与 Vmess 有何不同？
VLess 是由 V2Ray 开发者推出的新一代无加密传输协议，相比 Vmess 更轻量、效率更高。VLess 去除了内置加密逻辑，支持外部加密层如 TLS，使其更适合现代代理环境，尤其在高延迟网络中表现更稳定。
Netch 无法代理游戏怎么办？
若 Netch 无法代理游戏，需检查游戏进程是否被正确捕获，以及防火墙是否阻止了 TUN 模式。可尝试以管理员身份运行程序，或切换为 Socks 模式重新导入节点。
Shadowrocket 在使用订阅时要注意什么？
在 Shadowrocket 中添加订阅时，应确保链接以 https 开头且格式正确。此外，若节点更新失败，可尝试关闭缓存或重新获取订阅链接，以保证配置文件同步最新节点数据。
Trojan 协议是如何伪装流量的？
Trojan 利用 HTTPS 协议进行传输伪装，通过 TLS 加密实现高度隐蔽性。它让代理流量看起来与普通网站访问完全相同，从而难以被防火墙检测，是目前安全性较高的代理方案之一。
